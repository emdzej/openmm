Micro Machines in your browser

OpenMM runs here as openmm.wasm on the gasm runtime: the same module as on the desktop, a port of the original program's code, reading the tracks, the vehicles, the pictures and the music from your own copy of Micro Machines. Nothing from the game is on this site, and nothing you pick leaves your computer.

A work in progress: the menus, one- and two-player races and the sound run and are being checked against the original. See Status.

What you need

  • Micro Machines for DOS (Codemasters, 1994), the 720 KB floppy release (the program MICRO.EXE, 28,955 bytes): an image of the floppy (.img), or its files copied to a folder, or the installed game's folder. See Game data.
  • A browser with WebAssembly and Web Workers: a recent Chrome, Edge, Firefox or Safari.
  • Under 1 MB of browser storage to import the floppy (once; later visits start at once), or none to play without importing.
  • A keyboard.

The image is the whole 720 KB disk (FAT12). A folder holds its files (MICRO.COM, MICRO.EXE, SM.EXE, GAME1, ...), or is the folder the game was installed to.

    Importing copies what you picked into this site's private browser storage (OPFS). Playing without importing reads it from where it is, which you'll need to pick again next time.

    Options

    The default is the original's start, with one exception: the original asks for a symbol from the code card that came in the box before it starts, and OpenMM skips that unless you ask for it here. Each option is one of the game's parameters (see Status).

    Controls

    The game reads the keyboard as the original did. On GAME OPTIONS, F1-F6 change the controls, the sound and the smoothness, redefine the keys and show the credits; Enter plays, Esc quits. The default keys: player 1 ← → steer, ↑ accelerates, ↓ brakes, Enter selects; player 2 Z X steer, F accelerates, C brakes, G selects. In a race Space pauses and Esc leaves the race. Choose SPEAKER or BLASTER (the AdLib) with F3 for sound.

    Holding Esc for a second stops the game. In fullscreen the browser takes Esc to leave fullscreen. The settings (SETTINGS.DAT) are kept in this browser.
